{% extends "admin/base_site.html" %} {% load i18n %} {% comment %} One page's content, as cards. Replaces the sections table that used to sit on the Page form. That table showed position, label, type, visibility, a truncated copy of the markup, the markup itself and a lock flag in eight columns, and the markup won: editing a headline meant scrolling through 3,000 characters of HTML to find the row. Here each section is a card with the things an editor actually decides on -- what it says, what it looks like, whether it shows -- and the HTML is one click away on the section's own form. The markup is not lost by this. It is still the source of truth and still has to be, because the pages are a byte-exact mirror and a section's HTML is reassembled verbatim.
