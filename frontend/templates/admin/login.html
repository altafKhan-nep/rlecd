{% extends "admin/base_site.html" %} {% load i18n static %} {% comment %} Branded replacement for the Django admin login page. Overrides templates/admin/login.html at the project level, which is the documented way to restyle a single admin screen. The form contract with Django is preserved exactly: same action, same field names, csrf token, the `next` hidden input, the non-field error block and the password-reset link. Restyling a login page is only safe as long as none of that is dropped — a visually nicer page that silently loses the `next` field bounces staff back to the login screen after signing in.
